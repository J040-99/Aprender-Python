Lição 1: O teu primeiro "Olá Mundo"

Em Python, imprimir texto no ecrã é extremamente simples. Utilizamos a função print().

# Este é um comentário em Python
print("Olá, Mundo!")

Nota que não é necessário ponto e vírgula no final da instrução.

Lição 2: Variáveis e Tipos de Dados

As variáveis servem para armazenar informações. Em Python, não precisas de declarar o tipo.

  • Strings: texto entre aspas ("olá")
  • Inteiros: números sem casas decimais (10)
  • Floats: números com casas decimais (3.14)
  • Booleanos: True ou False

Dica: Usa type() para saber o tipo de uma variável.

Lição 3: Estruturas Condicionais (if/else)

Permitem tomar decisões no código. Python utiliza a indentação para definir blocos.

idade = 67

if idade >= 67:
    print("És maior de idade.")
else:
    print("Ainda és menor.")

A indentação (espaços no início) é obrigatória em Python!

Lição 4: Ciclos (for e while)

Os ciclos permitem repetir ações. O for itera sobre uma sequência.

# Ciclo for
for i in range(5):
    print(i)

# Ciclo while
contador = 0
while contador < 3:
    print(contador)
    contador += 1

Lição 5: Listas

As listas permitem armazenar múltiplos valores numa variável.

frutas = ["maçã", "banana", "laranja"]

# Acessar elementos
print(frutas[0])  # maçã

# Adicionar elemento
frutas.append("manga")

# Percorrer lista
for fruta in frutas:
    print(fruta)

Lição 6: Funções

As funções são blocos de código reutilizáveis. Definem-se com def.

def saudar(nome):
    print("Olá, " + nome + "!")

# Chamar a função
saudar("Maria")

# Função com retorno
def somar(a, b):
    return a + b

resultado = somar(5, 3)
print(resultado)
